# base/ — documentos e dados de entrada

Aqui ficam o documento-base do projeto e as planilhas de dados (checklist no fim de `../01-analise-critica-e-mapa-mestre.md`).

Regras (ver `../00-regras-do-projeto.md` §6):
- **Só versionar o conteúdo desta pasta com o repositório privado.** Enquanto ele for público, mantenha os arquivos fora do Git.
- **Não suba dados pessoais identificáveis** (nome, CPF, telefone, e-mail). Substitua por um id consistente que ligue as tabelas.
- Nomeie com data e tema, ex.: `2026-10_salas_shows_vendas_12m.xlsx`.
- Na dúvida sobre uma base, confirme com o DPO antes de subir.
