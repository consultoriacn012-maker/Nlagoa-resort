# Lagoa — repositório do site e do projeto Prospecção Geral

Este repositório tem duas partes:
- **Site** (Next.js + Supabase): landing page de captação "Lagoa Parque e Hotéis / Seja Sócio Lagoa Lovers".
- **Projeto Prospecção Geral** (`docs/prospeccao-geral/`): base de conhecimento do projeto estratégico de prospecção para multipropriedade do Grupo Lagoa Quente, conduzido por Gustavo.

Em qualquer pedido de análise, estratégia, KPI, funil, planilha ou material para a Diretoria, siga as regras permanentes abaixo e consulte o registro de informações (`docs/prospeccao-geral/02-registro-de-informacoes.md`) e o mapa mestre vigente (`docs/prospeccao-geral/01-analise-critica-e-mapa-mestre.md`).
