# base/ — documentos e dados de entrada

Coloque aqui o documento-base do projeto e as planilhas de dados (ver o checklist no fim de `../01-analise-critica-e-mapa-mestre.md`).

Antes de subir:
- **Não suba dados pessoais identificáveis** (nome, CPF, telefone, e-mail) para o repositório. Substitua por um id consistente que ligue as tabelas.
- Nomeie com data e tema, ex.: `2026-10_salas_shows_vendas_12m.xlsx`.
- Se o repositório for público ou compartilhado com terceiros, confirme com o DPO antes de subir qualquer base.
